# OWAS portfolio image upload

This branch is reserved for adding four approved OWAS portfolio screenshots.

Upload the optimized WebP files to **`static/images/owas/`**:

- `macro-overview.webp`
- `workforce-movement.webp`
- `compensation.webp`
- `enterprise-semantic-model.webp`

The current portfolio project pages already reference those exact paths. The image shortcode hides missing files, so no image will appear until the files are committed.

Use GitHub's **Add file → Upload files** on this branch, then commit directly to `owas-image-upload`. Review the Netlify deploy preview before merging the pull request.

Source visuals: OWAS macro dashboards v0.4 and synthetic enterprise Power BI semantic model.
